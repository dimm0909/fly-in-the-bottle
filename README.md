# fly-in-the-bottle

Виджет для рабочего стола: анатомическая 3D-муха в стеклянной банке, которую можно тыкать, вращать и трясти.
Electron + Three.js, прозрачное окно без рамки, которое на Linux/X11 может «жить на обоях». Поведением мухи
управляет **настоящая коннектома самца дрозофилы (MaleCNS, 164 606 нейронов)**, которая считается в отдельном
процессе.

## Что входит

- прозрачное окно без рамки; слои «на обоях» (под всеми окнами), «обычное» и «поверх всех»
- стеклянная банка с преломлением и хроматической аберрацией, рифлёная крышка, этикетка, тень
- анатомическая дрозофила из 39 мешей NeuroMechFly v2: двухзвенное IK ног, шаги «треногой», настоящий ход крыла
- мозг: симулятор коннектомы MaleCNS на C++ (`brain/`), событийный, ~0 нагрузки в покое
- запасная сценарная муха (полёт, посадка, чистка лапок, испуг, кувырок), если мозга нет
- синтез звука без аудиофайлов: жужжание, «тинь» стекла, «тик» о стекло
- тестовый стенд `--shot`: кадры и проверки без показа окна на экране
- документация на Sphinx в `docs/` (обзор, quickstart, архитектура, мозг, справочник API)

## Quickstart

1. Поставьте зависимости приложения (нужны Node.js и npm):

```bash
npm install
```

2. Запустите виджет:

```bash
npm start          # electron . --no-sandbox
```

Окно прозрачное, стоит в правом нижнем углу основного экрана и по умолчанию лежит **под всеми окнами**.
Если рабочий стол закрыт окнами, банки не видно: нажмите `Super+D` или выберите в меню (правая кнопка)
«Положение → Обычное окно» либо «Поверх всех окон».

`--no-sandbox` нужен на Ubuntu 24.04: непривилегированные user namespaces ограничены AppArmor, а `chrome-sandbox`
из npm-пакета не setuid; без флага окно остаётся пустым и без ошибок.

3. (Один раз, по желанию) подключите мозг:

```bash
npm run brain:setup   # скачает коннектому (~1,1 ГБ), соберёт граф и симулятор; понадобятся Python 3, g++, make, curl
npm run brain:check   # проверка симулятора
npm start
```

Сборка графа занимает ~30 секунд и пиково около **12 ГБ RAM**. Без этого шага виджет работает на запасной
сценарной мухе (`npm run start:scripted` включает её принудительно).

Если в терминале, запущенном из VS Code, `npm start` падает на `ipcMain` с выводом про `Node.js v24…`, в окружении
выставлен `ELECTRON_RUN_AS_NODE`: запустите `env -u ELECTRON_RUN_AS_NODE npm start`.

Полный разбор установки и типичные проблемы: [docs/quickstart.md](docs/quickstart.md).

## Управление

| Действие | Что происходит |
| --- | --- |
| Клик по мухе | «тычок»: муху отбрасывает, а касание попадает в нейроны той части тела, куда ткнули |
| Клик по стеклу | стук: банка вздрагивает, вибрация доходит до усиков и лап |
| Быстро подвести курсор к мухе | для мозга это приближающийся объект с той стороны, откуда идёт курсор |
| Перетаскивание по стеклу | вращает банку (есть инерция), резкий рывок встряхивает муху |
| Перетаскивание за крышку, либо Shift/Alt/Ctrl + перетаскивание | двигает виджет по столу (банка при этом раскачивается) |
| Правая кнопка | меню: звук, мозг, размер, положение, выход |

## Мозг

Данные: [MaleCNS v1.0](https://male-cns.janelia.org/) (Janelia FlyEM и партнёры, CC-BY): мозг и брюшной нервный
узел одной мухи. Берутся прослеженные нейроны (164 606) и связи от 5 синапсов (6,2 млн из 25,6 млн), знак связи - по
предсказанному нейромедиатору (ацетилхолин +; ГАМК, глутамат, гистамин −).

Модель - LIF по схеме [Shiu и др., Nature 2024](https://www.nature.com/articles/s41586-024-07763-9) (`brain/`,
C++): порог 7 мВ, τ_m = 20 мс, τ_syn = 5 мс, задержка 2 мс, шаг 1 мс. Событийная: спящие нейроны ничего не стоят.

```
тело ──касание, вибрация, приближение, ветер, нагрузка на лапы──▶ ток на сенсорные группы ──▶ МОЗГ
тело ◀──мощность лётных мышц, рулевые мышцы, мышцы ног/шеи/брюшка──── частоты пулов мотонейронов ◀──┘
```

Соответствия описаны в `tools/build_groups.py` (99 групп: сенсоры, моторные пулы, нисходящие нейроны). В коде тела
(`src/brainfly.js`) нет сценария «летать», «садиться» или «чиститься»: только физика (подъёмная сила нужна для
полёта, лапы липнут к стеклу) и коэффициенты.

**Что откалибровано, а что предположено** (подробности и таблицы: [docs/brain.md](docs/brain.md),
[docs/brain_model.md](docs/brain_model.md)):

- усиление синапса **0,15 мВ, а не 0,275** как у Shiu и др.: при 0,275 любой сильный вход зажигает всю сеть одним
  паттерном;
- **адаптация порога** (+0,1 мВ за спайк, τ = 1,5 с): без неё в коннектоме есть самоподдерживающиеся петли
  (восходящие → нисходящие → интернейроны VNC → восходящие), и «полёт» не прекращается никогда;
- исходящие связи мотонейронов отрезаны (их выход - мышца);
- знак руления - соглашение: избыток активности левых рулевых мышц поворачивает муху налево; приближение справа
  сильнее возбуждает левые рулевые мышцы, поэтому муха уходит от угрозы; уровни фонового входа подобраны эмпирически;
- фоновый шум 2 Гц включён, но **инертен**: до 30 Гц сеть молчит, с 40 Гц переходит в устойчивое возбуждение,
  промежуточного режима нет. Покоящаяся муха неподвижна, пока её не потревожат.

**Чего нет:** ходьбы (в LIF-сети нет ритмогенератора: ноги подёргиваются, но не шагают), зрения кроме детекторов
приближения и фонового света, биомеханики полёта. Это **не** «муха, которая сама летает по коннектоме» (такой
готовой не существует), а тело, чьи решения принимает настоящая нейросеть. GPU-бэкенд (CUDA) не делался: CPU-версия
дешёвая (в покое ~0, всплеск до ~0,5 ядра, в среднем ~27% ядра при активном использовании) и не мешает играм;
интерфейс `Backend` в `brain/brain.h` рассчитан на второй бэкенд.

## Документация

Sphinx-сайт на русском лежит в `docs/`: обзор, quickstart, управление, режимы запуска, архитектура, стекло, модель
мухи, мозг (данные, модель и калибровка, справочник групп и протокола), разработка, справочник API.

```bash
python3 -m venv --system-site-packages .venv   # если .venv ещё нет
.venv/bin/pip install -r docs/requirements.txt
make -C docs html                              # или: npm run docs
```

Готовый сайт: `docs/_build/html/index.html`. Сборка всегда полная (`clean` + `sphinx-build -E`), чтобы боковое меню не
расходилось с деревом страниц; каталоги `docs/_build/` и `docs/api/generated/` в git не хранятся.

## Проверки

Автоматических тестов на JS нет: виджет проверяется тестовым стендом `--shot` (кадры, поведение мухи, долгие прогоны),
а мозг - скриптом.

```bash
npm run brain:check                      # 9 проверок симулятора: тишина в покое, взлёт на угрозу,
                                         # локальный ответ на касание брюшка, градуированность
.venv/bin/python tools/bench_brain.py    # стоимость счёта и сверка серии с эталоном
npm run shot                             # кадр в shots/shot.png (окно уходит за экран)
```

Примеры скриптов для стенда и подводные камни: [docs/development.md](docs/development.md).

## Режимы запуска

| Команда | Что делает |
| --- | --- |
| `npm start` | обычный запуск; мозг стартует, если установлен и включён |
| `npm run start:scripted` | запасная сценарная муха (`--no-brain`) |
| `npm run shot` | режим скриншота: PNG с альфа-каналом без показа окна |
| `npm run brain:setup` | скачать коннектому и собрать мозг |
| `npm run brain:check` | проверить мозг |
| `npm run docs` | собрать документацию |

Флаги: `--no-brain`, `--layer=desktop\|normal\|top` (на один запуск), `--dev` (объект `window.__w`),
`--shot[=файл]`, `--script=файл.js`, `--delay=мс`. Не используйте `--debug`: его занимает Node. Настройки лежат в
`~/.config/fly-in-the-bottle/settings.json`. Подробнее: [docs/launch_modes.md](docs/launch_modes.md).

## Архитектура

Три процесса: главный процесс Electron (`main.js`, `brain-host.js`), рендерер (`src/*.js`: сцена Three.js, ввод, звук)
и сайдкар мозга (`brain/`, C++), с которым главный процесс говорит построчным текстовым протоколом. Стекло: муху
рисуют в отдельную текстуру с альфой, а шейдер стенки банки берёт её с преломлением и добавляет отражения
процедурной «студии». Частота кадров адаптивна: 60 при движении, 20 в покое. Схемы, IPC и главный цикл:
[docs/architecture.md](docs/architecture.md), [docs/rendering.md](docs/rendering.md).

## Структура проекта

```text
main.js                     # Electron: окно, меню, настройки, IPC, режим скриншота
preload.js                  # мост window.widget между рендерером и главным процессом
brain-host.js               # процесс-хозяин сайдкара мозга и его протокол
src/
  index.html                # страница, import map, CSP
  app.js                    # сцена, мышь, главный цикл кадра
  jar.js                    # банка, шейдер стекла, крышка, этикетка, тень
  env.js                    # процедурная «студия»: отражения (GLSL + PMREM)
  flymodel.js               # тело мухи: меши, скелет, IK ног
  fly.js                    # сценарная муха и общая механика (столкновения, поза, звук)
  brainfly.js               # муха с мозгом
  brainlink.js              # связь рендерера с сайдкаром
  motion.js                 # физика банки как целого
  audio.js                  # синтез звука
assets/fly/                 # 39 STL NeuroMechFly v2 (Apache-2.0), rig.json, лицензия
brain/                      # C++ сайдкар: brain.h, cpu.cpp, main.cpp, Makefile
tools/
  setup_brain.sh            # загрузка данных и сборка мозга
  build_brain_graph.py      # граф и таблица нейронов
  build_groups.py           # именованные группы нейронов
  build_fly_rig.py          # rig.json из rigging.yaml
  brain_client.py           # Python-клиент сайдкара
  check_brain.py            # проверки мозга
  bench_brain.py            # стоимость счёта
  explore/                  # эксперименты калибровки
docs/                       # Sphinx-документация
data/ shots/ .venv/         # не хранятся в git: данные и граф, кадры стенда, окружение Python
```

## Заметки

- Положение окна по умолчанию - «на обоях»: тип окна X11 `desktop`, всегда под остальными, на всех рабочих столах,
  вне панели задач и Alt-Tab. Кликабельность в этом слое на проверенной машине не проверялась (экран был целиком
  закрыт окнами); при проблемах выберите слой «Обычное окно».
- Не отправляйте синтетический ввод (`xdotool` и подобное) на настоящий рабочий стол для проверки виджета:
  проверяйте события `PointerEvent`, отправленные внутри страницы (см. [docs/development.md](docs/development.md)).
- Данные: коннектома MaleCNS - Janelia FlyEM, Кембридж, Google (CC-BY); меши и скелет тела - NeuroMechFly v2
  (NeLy-EPFL/flygym, Apache-2.0, лицензия в `assets/fly/LICENSE-flygym.txt`); модель нейрона - Shiu и др. 2024.
