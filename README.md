# fly-in-the-bottle

Виджет для рабочего стола: муха в стеклянной банке, которую можно тыкать. Электрон + Three.js,
прозрачное окно без рамки. Муха — анатомическая 3D-модель дрозофилы, а её поведением управляет
**настоящая коннектома самца мухи (MaleCNS, 164 606 нейронов)**, которая считается в отдельном процессе.

## Запуск

```bash
npm install
npm run brain:setup   # один раз: скачивает коннектому (~1,1 ГБ), собирает граф и симулятор
npm start             # electron . --no-sandbox
```

Без `brain:setup` виджет работает на запасной «сценарной» мухе (`npm run start:scripted` включает её
принудительно). `--no-sandbox` нужен на Ubuntu 24.04, где AppArmor запрещает пользовательские namespace для Electron.

## Управление

| Действие | Что происходит |
| --- | --- |
| Клик по мухе | «тычок»: её отбрасывает, а касание попадает в нейроны той части тела, куда ткнули |
| Клик по стеклу | стук: вибрация доходит до усиков и лап, банка вздрагивает |
| Быстро подвести курсор к мухе | для мозга это приближающийся объект (looming) с той стороны, откуда идёт курсор |
| Перетаскивание по стеклу | вращает банку (есть инерция), резкий рывок встряхивает муху |
| Перетаскивание за крышку, либо Shift/Alt/Ctrl + перетаскивание | двигает виджет по столу (банка при этом раскачивается) |
| Правая кнопка | меню: мозг, звук, размер, положение, выход |

Положение окна по умолчанию — «на обоях»: тип окна `desktop`, виджет лежит под всеми окнами, на всех
рабочих столах, не в панели задач и не в Alt-Tab. Чтобы его увидеть, покажите рабочий стол (`Super+D`)
или выберите в меню «Обычное окно» / «Поверх всех окон».

## Мозг

Данные: [MaleCNS v1.0](https://male-cns.janelia.org/) (Janelia FlyEM и партнёры, лицензия CC-BY): мозг и
брюшной нервный узел одной мухи. Берутся прослеженные нейроны (164 606) и связи от 5 синапсов (6,2 млн из
25,6 млн), знак связи — по предсказанному нейромедиатору (ацетилхолин +; ГАМК, глутамат, гистамин −).

Модель — LIF по схеме [Shiu и др., Nature 2024](https://www.nature.com/articles/s41586-024-07763-9)
(`brain/`, C++): порог 7 мВ, τ_m = 20 мс, τ_syn = 5 мс, задержка 2 мс, шаг 1 мс. Событийная: спящие нейроны
ничего не стоят, покойная муха считается за ~0, отклик на угрозу занимает до ~0,5 ядра на 1–2 секунды.

```
тело ──касание, вибрация, приближение, ветер, нагрузка на лапы──▶ ток на сенсорные группы ──▶ МОЗГ
тело ◀──мощность лётных мышц, рулевые мышцы, мышцы ног/шеи/брюшка──── частоты пулов мотонейронов ◀──┘
```

Соответствия описаны в `tools/build_groups.py` (сенсоры: фоторецепторы, JO, щетинки, кампаниформные сенсиллы,
гальтеры, детекторы приближения LPLC2/LC4/…; выходы: DLM/DVM, рулевые мышцы крыла, ноги по парам и
сторонам, шея, брюшко, хоботок, нисходящие нейроны). В коде тела (`src/brainfly.js`) нет сценария «летать»,
«садиться» или «чиститься»: только физика (подъёмная сила нужна для полёта, лапы липнут к стеклу) и коэффициенты.

### Что откалибровано, а что предположено

Чтобы не выдавать это за чистую эмерджентность:

- **Усиление синапса 0,15 мВ, а не 0,275 как у Shiu и др.** При 0,275 любой достаточно сильный вход
  (ветер, касание, опора лап) зажигает всю сеть одним и тем же паттерном. При ~0,15 отклики градуированы и
  различаются по стимулу (`tools/explore/explore3.py`).
- **Адаптация порога** (+0,1 мВ за спайк, τ = 1,5 с). Без неё в коннектоме есть самоподдерживающиеся петли
  (ascending → DN → VNC → ascending), и «полёт» не прекращается никогда (`explore5.py`, `explore6.py`).
- Исходящие связи мотонейронов отрезаны: их выход — мышца, а не другие нейроны.
- Знак руления выбран так, чтобы муха уворачивалась от угрозы; уровни фонового входа (свет 8 мВ, нагрузка на
  лапы 7/5 мВ) и слабый шум на механорецепторах (2 Гц) подобраны эмпирически. Шум даёт редкие самопроизвольные
  подёргивания вместо статуи.
- Полёт длится, пока мощность DLM/DVM (сглаженная: быстрый подъём, медленный спад) не упадёт: это модель мышцы и
  инерции крыла, а не сценарий.

### Чего нет

Ходьбы (в LIF-сети нет ритмогенератора: ноги подёргиваются, но не шагают), зрения кроме детекторов приближения и
фоновой освещённости, биомеханики полёта и аэродинамики. Это **не** «муха, которая сама летает по коннектоме»
(такой готовой не существует), а тело, чьи решения принимает настоящая нейросеть с данными о её связях. GPU-бэкенд
(CUDA) не делался: при таких затратах CPU-версия дешевле и не мешает играм. Интерфейс `brain/brain.h` рассчитан
на добавление второго бэкенда.

## Как устроено

- `main.js` — окно, меню, настройки (`~/.config/fly-in-the-bottle/settings.json`), запуск мозга (`brain-host.js`).
- `brain/` — симулятор (`cpu.cpp`, протокол в `main.cpp`); `tools/` — сборка графа и групп, проверки, исследования.
- `src/jar.js` — банка и стекло; `src/flymodel.js` — 39 мешей NeuroMechFly v2 + скелет + IK ног;
  `src/fly.js` — сценарная муха (запасной режим); `src/brainfly.js`, `src/brainlink.js` — муха с мозгом.
- Стекло: муху рисуют в отдельную текстуру с альфой, шейдер стенки берёт её с преломлением (сдвиг по нормали +
  хроматическая аберрация) и добавляет отражения процедурной «студии».
- Частота кадров адаптивна: 60 при движении, 20 в покое.

## Разработка

`npm run shot` рендерит кадр в `shots/shot.png` (окно уходит за экран). Флаги: `--script=файл.js` (JS в странице,
результат печатается), `--delay=мс`, `--dev` (объект `window.__w`), `--layer=desktop|normal|top`, `--no-brain`.
Не используйте `--debug`: его занимает Node. `npm run brain:check` проверяет симулятор (тишина в покое, взлёт на
угрозу, локальный ответ на касание брюшка, градуированность).
