# Быстрый старт

## Что понадобится

| Компонент | Зачем | Замечание |
| --- | --- | --- |
| Node.js и npm | Приложение (Electron 41, Three.js) | Проверено на Node 20.20 и npm 10.8. |
| Linux с X11 и композитным менеджером | Прозрачное окно и слой «на обоях» | Проверено на Ubuntu 24.04, GNOME 46, X11. Wayland не проверялся. |
| Windows 10/11 | То же | Код написан, но **на Windows не запускался**; см. [windows](windows.md). |
| Python 3 | Только для мозга | Проверено на Python 3.12. На Windows подойдёт `py -3` или `python`. |
| Компилятор C++17 | Только для мозга | `g++`, `clang++`, MSVC (`cl`); если ничего нет, `npm run brain:setup` сам поставит `zig` из PyPI (около 80 МБ). Проверено на g++ 13.3 и zig. |
| ~1,5 ГБ на диске | Только для мозга | 1,1 ГБ данные (из них 1,05 ГБ загрузка) + 57 МБ граф и таблица нейронов + окружение Python с `pyarrow` и `pandas`. |
| ~2 ГБ свободной RAM на несколько секунд | Только для мозга, сборка графа | Пик `tools/build_brain_graph.py`: 1,9 ГБ, около 14 секунд; сам мозг потом занимает около 90 МБ. |

`make`, `curl` и `bash` больше не нужны: за загрузку и сборку отвечает `tools/dev.js` (Node). Без мозга нужен только
Node.js: виджет запустится на запасной сценарной мухе.

## Установка приложения

```bash
npm install
```

Вместе с Electron и Three.js ставится необязательный пакет `koffi` (он нужен только на Windows, чтобы прижимать окно
ко дну порядка окон; если он не установился, npm просто пропускает его).

## Первый запуск

```bash
npm start
```

Скрипт выполняет `node tools/dev.js start`, а тот запускает `electron .` с двумя поправками для окружения:

- на Linux добавляет `--no-sandbox`: на Ubuntu 24.04 непривилегированные user namespaces ограничены AppArmor
  (`kernel.apparmor_restrict_unprivileged_userns=1`), а `chrome-sandbox` из npm-пакета не имеет прав setuid; без флага
  окно на проверенной машине остаётся пустым и без единой ошибки в консоли. На Windows и macOS песочница остаётся;
- удаляет из окружения `ELECTRON_RUN_AS_NODE` (его выставляют терминалы VS Code, и Electron тогда запускает
  `main.js` как обычный Node).

Что вы увидите. Окно прозрачное и без рамки, по умолчанию оно стоит в правом нижнем углу основного экрана и лежит
**под всеми окнами**. На Linux это тип окна `desktop` (на всех рабочих столах, не в панели задач и не в Alt-Tab),
на Windows - неактивируемое окно-инструмент, прижатое ко дну порядка окон. Если рабочий стол закрыт окнами, банки
не видно: покажите рабочий стол (`Super+D`) или выберите в меню (правая кнопка) «Положение → Обычное окно» либо
«Поверх всех окон».

Запущенный без мозга виджет живёт на сценарной мухе. Управление (в том числе масштаб колесом мыши) описано на
странице [controls](controls.md).

## Установка мозга

```bash
npm run brain:setup
```

Команда `node tools/dev.js setup-brain` делает за один проход:

1. скачивает три файла коннектомы MaleCNS v1.0 (Janelia FlyEM, CC-BY) с `storage.googleapis.com` в
   `data/malecns/` встроенным HTTPS-клиентом Node: связность (1,05 ГБ), аннотации (14 МБ), нейромедиаторы (43 МБ).
   Уже скачанные файлы пропускаются, недокачанные лежат как `*.part` и не считаются готовыми;
2. создаёт `.venv` (с доступом к системным пакетам) и ставит в него `pyarrow` и `pandas`;
3. `tools/build_brain_graph.py` строит граф `data/brain/graph.bin` и таблицу нейронов
   `data/brain/neurons.feather` (около 14 секунд, пик 1,9 ГБ RAM: файл связности читается порциями Arrow);
4. `tools/build_groups.py` строит именованные группы нейронов `data/brain/groups.txt`;
5. собирает симулятор `data/brain/brain` (на Windows `brain.exe`): пробует `g++`, `c++`, `clang++` (переменная `CXX`
   выбирает другой), на Windows затем MSVC `cl`, и если компилятора нет, ставит `ziglang` из PyPI и собирает им.

Каталог `data/` игнорируется git'ом. Если файл `data/brain/brain` на месте, следующий `npm start` сам запустит мозг:
в меню появится отмеченный пункт «Мозг: коннектом MaleCNS». Только пересобрать симулятор (после правок `brain/`)
можно командой `npm run brain:compile`.

Первые 1-2 секунды после запуска окно пустое: мозг «прогревается» в состоянии покоя (иначе включение всех сенсоров
разом даёт залп, которого у настоящей мухи не бывает), и только потом появляется банка.

### Проверка мозга

```bash
npm run brain:check
```

Ожидаемый вывод (числа могут слегка отличаться):

```text
ok   graph loaded (164606 neurons, 6234901 connections)
ok   idle network is silent
ok   idle network is free (0.1 ms for 2 s)
ok   looming drives the flight muscles (dlm 152 dvm 79 Hz)

ok   abdomen touch reaches abdominal motor neurons (abd 20 Hz)
ok   abdomen touch is not a take-off (dlm 17 Hz)
ok   response grows with stimulus strength (dvm 81 < 100 < 113)
```

## Запуск без мозга

```bash
npm run start:scripted
```

Это `node tools/dev.js start --no-brain`. Так же ведёт себя виджет, если `brain:setup` не выполнялся.

## Сборка документации

```bash
npm run docs
```

Команда ищет `.venv` (его создаёт `brain:setup`; без него `python3 -m venv --system-site-packages .venv`), при
необходимости ставит `docs/requirements.txt` и **всегда делает полную пересборку** `docs/_build`, чтобы боковое меню
и дерево страниц не расходились после правок `toctree`. Готовый сайт лежит в `docs/_build/html/index.html`.

Без npm то же самое делают `make -C docs html` или `.venv/bin/sphinx-build -b html -E docs docs/_build/html`.

## Частые проблемы

| Симптом | Причина и решение |
| --- | --- |
| `TypeError: Cannot read properties of undefined (reading 'handle')` и в конце `Node.js v24…` | Electron запущен как обычный Node из-за `ELECTRON_RUN_AS_NODE` (терминалы VS Code). `npm start` эту переменную убирает; если вы запускаете `electron .` руками, выполните `env -u ELECTRON_RUN_AS_NODE …`. |
| Окно пустое, банки нет, ошибок тоже нет (Linux) | Запуск без `--no-sandbox`. Используйте `npm start`, а не голый `electron .`. |
| Виджета не видно | Он под окнами. `Super+D` или меню → «Положение». |
| Окно непрозрачное, вместо фона чёрный прямоугольник | Вероятно, нет композитного менеджера окон. Не проверялось: на GNOME/X11 прозрачность работает из коробки. |
| В меню «Мозг: не установлен (npm run brain:setup)» | Не выполнен `npm run brain:setup` или не собран `data/brain/brain[.exe]`. |
| `brain:setup`: `Python 3 was not found` | Поставьте Python 3 (на Windows `py -3` из установщика python.org). |
| `brain:setup` останавливается на сборке графа, в выводе `Killed` | Не хватило RAM: сборка пиково занимает ~2 ГБ. Закройте тяжёлые приложения и повторите; уже скачанные файлы заново не скачиваются. |
| `brain:setup`: ошибка загрузки (`HTTP …`) | Загрузка повторяется запуском той же команды; `*.part` от прерванной загрузки перезаписывается. |
| Нет звука | В меню отключён «Звук жужжания» либо выключен системный звук; звук синтезируется на лету, файлов нет. |
| Второй запуск ничего не делает | Разрешён один экземпляр: повторный запуск просто показывает уже запущенное окно. |
| Виджет стал слишком большим или маленьким | Колесо мыши над виджетом меняет масштаб; сбросить: меню → «Размер» → «Сбросить масштаб (100%)». |

Более глубокие детали (флаги, слои, файл настроек, режим скриншотов): [launch_modes](launch_modes.md).
