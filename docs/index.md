# Fly in the Bottle

Fly in the Bottle - это виджет для рабочего стола (Linux/X11; Windows поддерживается, но
не проверялся): анатомическая 3D-муха в стеклянной банке, которую можно тыкать, вращать,
трясти и приближать колесом мыши. Поведением мухи
управляет настоящая коннектома самца дрозофилы (MaleCNS, 164 606 нейронов),
которая считается в отдельном процессе; без неё виджет работает на запасной
сценарной мухе.
