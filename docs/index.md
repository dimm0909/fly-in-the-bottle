# Fly in the Bottle

Fly in the Bottle - это виджет для рабочего стола: анатомическая 3D-муха в
стеклянной банке, которую можно тыкать, вращать и трясти. Поведением мухи
управляет настоящая коннектома самца дрозофилы (MaleCNS, 164 606 нейронов),
которая считается в отдельном процессе; без неё виджет работает на запасной
сценарной мухе.
