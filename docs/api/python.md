# Python-инструменты

Скрипты в `tools/` готовят данные и проверяют мозг. Запускаются из корня проекта интерпретатором `.venv`
(`.venv/bin/python tools/…` на Linux, `.venv\Scripts\python.exe tools\…` на Windows) или одной командой на любой
системе: `node tools/dev.js py tools/скрипт.py [аргументы]`. Сборкой и загрузкой занимается `tools/dev.js` (Node), а не
Python-скрипт.

## Скрипты

| Скрипт | Аргументы | Что делает |
| --- | --- | --- |
| `build_brain_graph.py` | `--min-syn N` (5) | Строит `data/brain/graph.bin` и `neurons.feather` из трёх файлов MaleCNS. Файл связей читается порциями Arrow: пик около 1,9 ГБ RAM, около 14 с. |
| `build_groups.py` | - | Строит `data/brain/groups.txt` и `groups.json` (размеры) и печатает список групп. Файлы пишутся с `\n` на всех системах. |
| `build_fly_flybody.py` | `--src`, `--out` | Строит `assets/fly/flybody/rig.json` и `meshes.bin` из клона FlyBody (`data/flybody`, см. [fly_model](../fly_model.md)). |
| `probe_flybody.py` | - | Контрольные проекции позы покоя FlyBody (нужен `matplotlib`). |
| `check_brain.py` | - | Девять проверок сайдкара; код возврата 0 при успехе, 1 при провале. |
| `bench_brain.py` | - | Печатает стоимость счёта (простой, всплеск, спад, свет) и сверяет серию со значением 152/79/233/35/21/13. |
| `explore/explore1.py … explore11.py` | `explore3.py --final`; `explore11.py ЧАСТОТА [СЕКУНД]` | Эксперименты калибровки, см. таблицу ниже. |

### Эксперименты калибровки

Каждый скрипт запускает сайдкар и печатает таблицы, использованные в [brain_model](../brain_model.md). Скрипты
писались на разных этапах калибровки, поэтому каждый **явно задаёт свои параметры** (`dt`, адаптация, усиление):
результат не зависит от умолчаний сайдкара. Числа в документации взяты из повторных запусков; вблизи усиления
0,15 результат чувствителен к мелким изменениям модели, поэтому цитируйте запуск, а не память.

| Скрипт | Вопрос |
| --- | --- |
| `explore1.py` | Оживает ли сеть: простой, свет, приближение справа. |
| `explore2.py` | Отклик на ветер, касание, вибрацию, опору лап и приближение (при `w_syn = 0,275`). |
| `explore3.py` | Развёртка общего усиления синапса; с `--final` - в боевой конфигурации (шаг 1 мс, адаптация). Печатает таблицу для документации. |
| `explore4.py` | Доза, боковая асимметрия и временной ход отклика на приближение. |
| `explore5.py` | Самоподдерживающаяся активность: что её гасит. |
| `explore6.py` | Какие нейроны поддерживают активность. |
| `explore7.py` | Адаптация порога и отрезание выходов мотонейронов. |
| `explore8.py` | Поддерживают ли полёт обратные связи тела при адаптации. |
| `explore9.py` | Сравнение шагов 0,5 / 1,0 / 0,25 мс. |
| `explore10.py` | Спонтанная активность при разном уровне шума (короткие прогоны). |
| `explore11.py` | Длинные (300 с) прогоны шума на итоговом фоне покоя: сколько всплесков и уходит ли сеть в устойчивое возбуждение. |

## brain_client

Модуль `tools/brain_client.py` - клиент сайдкара, тот же протокол, что у виджета (имя исполняемого файла выбирается
по платформе: `brain` или `brain.exe`). Пример:

```python
import sys
sys.path.insert(0, 'tools')
from brain_client import Brain

b = Brain()                       # запускает data/brain/brain
b.drive('looming_R', 12)          # ток 12 мВ на детекторы приближения справа
b.advance(200)
rates = b.rates(150)              # Гц на нейрон по группам
print(rates['mn_dlm_L'], rates['dn_gf_R'])
b.close()
```
