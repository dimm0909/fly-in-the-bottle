# Режимы запуска

Все режимы стартуют из одного `main.js`; различаются npm-скриптом и флагами командной строки.

## npm-скрипты

| Скрипт | Команда | Когда использовать |
| --- | --- | --- |
| `npm start` | `electron . --no-sandbox` | Обычный запуск. Мозг стартует, если он установлен и включён в настройках. |
| `npm run start:scripted` | `electron . --no-sandbox --no-brain` | Принудительно запасная сценарная муха. |
| `npm run shot` | `electron . --no-sandbox --shot` | Рендер одного кадра в PNG без показа окна на экране (см. ниже). |
| `npm run brain:setup` | `bash tools/setup_brain.sh` | Один раз: скачать коннектому и собрать мозг. |
| `npm run brain:check` | `.venv/bin/python tools/check_brain.py` | Проверить собранный симулятор. |
| `npm run docs` | `make -C docs html` | Собрать эту документацию. |

## Флаги командной строки

Всё после `--` в `npm start -- …` попадает в Electron. Флаги приложения читает `main.js`; флаги Chromium
(`--no-sandbox` и др.) обрабатывает сам Electron.

| Флаг | Значение |
| --- | --- |
| `--no-sandbox` | Отключает песочницу Chromium; без него на Ubuntu 24.04 окно остаётся пустым, см. [quickstart](quickstart.md). |
| `--no-brain` | Не запускать мозг в этом запуске (сохранённая настройка не меняется). |
| `--layer=desktop\|normal\|top` | Переопределяет сохранённый слой окна только на этот запуск. |
| `--dev` | Отдаёт странице объект `window.__w` (сцена, муха, банка, мозг…) и включает отладочный лог указателя. |
| `--shot[=файл.png]` | Режим скриншота: отрисовать, сохранить PNG с альфа-каналом и выйти. По умолчанию `shots/shot.png`. |
| `--script=файл.js` | Только с `--shot`: JS, выполняемый в странице до снимка; его результат печатается в лог. |
| `--delay=мс` | Только с `--shot`: пауза перед снимком после скрипта (по умолчанию 1500). |

```{warning}
Не используйте флаг `--debug`: Node считает его флагом отладчика и завершает процесс с кодом 9.
Для этого и введён `--dev`.
```

## Слои окна

| Слой | Как устроено | Замечания |
| --- | --- | --- |
| `desktop` (по умолчанию) | Тип окна X11 `_NET_WM_WINDOW_TYPE_DESKTOP`: окно лежит под всеми остальными, на всех рабочих столах, скрыто из панели задач и Alt-Tab. | Виджет не виден, пока рабочий стол закрыт окнами. Тип нельзя сменить у живого окна, поэтому смена слоя пересоздаёт окно. |
| `normal` | Обычное окно без рамки. | Удобно для разработки. |
| `top` | Поверх всех окон (`setAlwaysOnTop(true, 'screen-saver')`). | Мешает работе, но банку всегда видно. |

Окно всегда `frame: false`, `transparent: true`, без тени и без изменения размера, показывается через
`showInactive()` (не забирает фокус). В `main.js` включён переключатель Chromium
`enable-transparent-visuals`: без него на Linux у окна не будет альфа-канала.

## Размеры

Окно сохраняет пропорцию 0,72, чтобы сцена масштабировалась равномерно.

| Размер | Пиксели |
| --- | --- |
| S | 288×400 |
| M (по умолчанию) | 360×500 |
| L | 468×650 |

## Файл настроек

`~/.config/fly-in-the-bottle/settings.json` (каталог `userData` Electron), создаётся при первом сохранении.

| Ключ | По умолчанию | Значение |
| --- | --- | --- |
| `x`, `y` | `null` | Положение окна; `null` - правый нижний угол основного экрана. Хранится при отпускании крышки и в меню. При загрузке положение зажимается в пределы доступных мониторов. |
| `size` | `"M"` | `S`, `M` или `L`. |
| `layer` | `"desktop"` | `desktop`, `normal` или `top`. |
| `sound` | `true` | Включён ли звук. |
| `brain` | `true` | Включён ли мозг (действует, если он установлен). |

Разрешён один экземпляр: повторный запуск просто показывает уже запущенное окно
(`requestSingleInstanceLock`).

## Режим скриншотов и тестовый стенд

`--shot` - основной инструмент разработки. Он нужен, чтобы получать кадры и проверять поведение, не
трогая рабочий стол.

1. Окно создаётся у `x=-5000, y=-5000`, за пределами экрана, и делается прозрачным для мыши
   (`setIgnoreMouseEvents(true)`). Скрытое (`show: false`) окно не годится: у него `requestAnimationFrame`
   срабатывает примерно раз в секунду, и анимация не идёт.
2. Настройки не читаются и не сохраняются (`saveSettings()` в режиме скриншота ничего не пишет); нативное
   меню не открывается.
3. Стенд ждёт до 10 секунд, пока страница построит сцену (`window.__w`): загрузка ассетов и прогрев мозга
   асинхронны.
4. Если задан `--script`, файл выполняется в главном мире страницы (`executeJavaScript`). Если он
   возвращает значение (например, `async`-функцию), результат печатается строкой `script result: {...}`;
   после него печатаются границы окна `bounds: {...}`.
5. Через `--delay` мс делается `capturePage()` и сохраняется PNG **с прозрачностью**; процесс выходит.

Пример: тычок по мухе и снимок.

```js
// poke.js
(async () => {
  const w = window.__w;
  w.fly.touch('c_head', 0);
  await new Promise((r) => setTimeout(r, 800));
  return { state: w.fly.state, power: w.fly.power };
})()
```

```bash
env -u ELECTRON_RUN_AS_NODE npx electron . --no-sandbox --shot=shots/poke.png --script=poke.js --delay=200
```
